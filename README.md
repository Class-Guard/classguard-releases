# ClassGuard

ClassGuard locks the games, apps and websites you choose during class, while homework is unfinished, and for focus sessions. Free for Windows and Mac.

**Download: https://class-guard.github.io/classguard-releases/**

- **Windows:** run `ClassGuard-Setup.exe` from the [latest release](https://github.com/Class-Guard/classguard-releases/releases/latest).
- **Mac:** open `ClassGuard-Mac.zip` from the [latest release](https://github.com/Class-Guard/classguard-releases/releases/latest) and move ClassGuard to Applications.

Installed copies update themselves. Every update is signed and checked before it installs. This repository holds releases and the download page only.
